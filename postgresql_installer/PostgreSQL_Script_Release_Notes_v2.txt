[PostgreSQL Install Script Release Notes]

v0.1
- PostgreSQL 소스 빌드 설치 스크립트 초안 작성
- 서버 리소스(CPU, Memory) 자동 조회 기능 추가
- 기본 설치 경로(/postgres, /pgdata) 및 포트(5432) 설정 기능 구현
- Step 7: initdb 수행 및 postgresql.conf 기본 설정 생성

v0.2
- postgresql.conf 관리 방식 개선: 임시 생성 후 DATA_PATH로 이동 및 원본 삭제 로직 추가
- 설치 완료 후 로그 경로(Log Path) 출력 정보 보강

v0.3
- 로케일 설정 변경: lc_messages를 'ko_KR.utf8'에서 'en_US.utf8'로 변경하여 시스템 메시지 영문화
- Archive 모드 사용 여부 선택 기능(Step 8) 추가 및 경로 설정 자동화

v0.4
- 서비스 자동 시작 및 상태 확인 로직 추가
- pg_ctl start 실행 후 pg_isready를 이용한 서버 기동 여부 체크(최대 10초 대기)
- 설치 완료 후 psql 접속 테스트 및 버전 정보 출력 기능 구현

v0.5
- 중복 설치 방지 로직(Step 0) 추가: 기존 postgres 프로세스 구동 여부 확인 및 사용자 경고
- 백업(Backup) 영역 설정 기능(Step 9) 추가: pg_dump 및 basebackup 경로 관리
- 백업 자동화 지원: 백업 주기 선택 기능 및 크론탭(cron) 설정 지원

v0.6
- HA(High Availability) 구성 기능 추가: Streaming Replication 설정 지원
- Primary/Standby 호스트 정보 수집 및 복제 전용 유저(replicator) 생성/패스워드 설정 기능 구현
- SSH 포트 및 복제 로그 관리 기능 추가

v0.7
- 설치 프로세스 안정화 및 사용자 인터페이스(UI) 텍스트 개선
- HA 구성 시 출력되는 정보 요약 보강 (Primary, Standby, 복제유저 정보 표시)
- 전체 설치 경로(Engine, Data, Log, Archive, Backup)에 대한 최종 요약 출력 기능 강화

v0.8 (Latest)
- 설치 모드 이원화: Single(로컬 설치) 및 HA(클러스터 구성) 모드 선택 기능 도입
- 분산 고가용성 아키텍처 지원: Patroni + etcd 기반의 자동 Failover 클러스터 구성 자동화
- 원격 배포 자동화: etcd 서버에서 빌드 후 Primary/Standby 서버로 scp를 이용한 엔진/데이터 배포 로직 추가
- 패키지 종속성 관리: Patroni, etcd, psycopg2 등 클러스터 구동을 위한 필수 패키지 설치 자동화
- 관리 도구 통합: patronictl을 이용한 클러스터 상태 확인 및 Switchover 가이드 출력
