================================================================
  1. 스크립트 개요
================================================================

이 스크립트 셋은 폐쇄망(인터넷 차단) 환경에 PostgreSQL을
안전하게 설치하기 위한 2단계 자동화 도구입니다.

  [STEP 1] postgresql_download_0.6.sh   (외부망 서버에서 실행)
           → 필요한 패키지를 모두 다운로드하여 하나의 디렉토리로 묶음

  [STEP 2] postgresql_install.sh        (폐쇄망 서버에서 실행)
           → 다운로드된 패키지로 PostgreSQL 설치 및 구성


================================================================
  2. 지원 설치 모드
================================================================

  ┌─────────────┬────────────────────────────────────────────┐
  │  모드        │  설명                                       │
  ├─────────────┼────────────────────────────────────────────┤
  │  single     │  단일 서버에 PostgreSQL만 설치              │
  │             │  - 로컬 서버 1대                            │
  │             │  - 백업(pg_basebackup) 자동 구성 가능       │
  ├─────────────┼────────────────────────────────────────────┤
  │  ha         │  3노드 HA 구성                              │
  │             │  - etcd 서버 (설치 실행 서버)               │
  │             │  - Primary DB 서버                          │
  │             │  - Standby DB 서버                          │
  │             │  - Patroni 기반 자동 Failover               │
  └─────────────┴────────────────────────────────────────────┘


================================================================
  3. 사전 준비 사항
================================================================

  ■ 공통 (single / ha 모두)
  ─────────────────────────────────────────
  □ 외부망 서버 1대 (다운로드용)
    - tar, curl 또는 wget, pip3 설치됨
    - 인터넷 접속 가능
    - 사용 가능한 디스크: 최소 3GB 이상 (HA 시 5GB 이상)

  □ 폐쇄망 서버 (설치 대상)
    - OS: Rocky Linux 9 (x86_64)
    - 설치 실행 유저: postgres (또는 동일 계정)
    - 사용 가능한 디스크: 엔진 + 데이터 + 로그 합산 충분히


  ■ HA 모드 추가 사전 준비
  ─────────────────────────────────────────
  □ 서버 3대 준비
    - etcd 서버 (postgresql_install.sh 실행 서버) [port: 22, 2379]
    - Primary DB 서버 [port: 22, 5432, 8008]
    - Standby DB 서버 [port: 22, 5432, 8008]

  □ 네트워크 / 방화벽
    - SSH 포트 (기본 22): 3대 상호 접속 가능
    - PostgreSQL 포트 (기본 5432): DB 서버 간 접속 가능
    - etcd 클라이언트 포트 (2379): DB 서버 → etcd 서버
    - etcd 피어 포트 (2380): etcd 내부 통신
    - Patroni REST API 포트 (8008): 서버 간 상호 접속 가능

  □ /etc/hosts 등록 (3대 모두)
    예시:
      192.168.90.99   etcd-server
      192.168.90.100  primary-db
      192.168.90.101  standby-db

  □ SSH 키 교환 (etcd 서버 기준)
    - etcd → Primary: 패스워드 없이 SSH 접속 가능
    - etcd → Standby: 패스워드 없이 SSH 접속 가능

  □ sudo NOPASSWD 설정 (Primary / Standby 서버)
    - postgres 유저가 sudo 명령을 패스워드 없이 실행 가능해야 함
    (systemd 서비스 등록, rpm 설치 등에 필요)


================================================================
  4. 사전 구성 방법
================================================================

  ■ 4-1. /etc/hosts 등록 (3대 모두 동일하게 적용)
  ─────────────────────────────────────────────────
  root 계정으로 각 서버에서 실행:

    $ sudo vi /etc/hosts

    추가할 내용 (IP는 실제 환경에 맞게 수정):
      192.168.90.99   etcd-server
      192.168.90.100  primary-db
      192.168.90.101  standby-db


  ■ 4-2. SSH 키 생성 및 교환 (etcd 서버에서 실행)
  ─────────────────────────────────────────────────
  etcd 서버의 postgres 유저로 실행:

    # SSH 키 생성 (이미 있으면 생략)
    $ ssh-keygen -t rsa -N "" 

    # Primary 서버로 공개키 복사
    $ ssh-copy-id -p 22 postgres@primary-db

    # Standby 서버로 공개키 복사
    $ ssh-copy-id -p 22 postgres@standby-db

    # 접속 확인
    $ ssh postgres@primary-db "hostname"
    $ ssh postgres@standby-db "hostname"


  ■ 4-3. sudo NOPASSWD 설정 (Primary / Standby 서버)
  ─────────────────────────────────────────────────────
  Primary / Standby 서버에서 root 계정으로 실행:

    $ echo 'postgres ALL=(ALL) NOPASSWD: ALL' \
        > /etc/sudoers.d/postgres
    $ chmod 440 /etc/sudoers.d/postgres

    # 적용 확인 (postgres 유저로 전환 후 테스트)
    $ su - postgres
    $ sudo -n true && echo "sudo OK"


  ■ 4-4. 방화벽 설정 (해당 서버별로 적용)
  ─────────────────────────────────────────────────
  etcd 서버:
    $ sudo firewall-cmd --permanent --add-port=2379/tcp
    $ sudo firewall-cmd --permanent --add-port=2380/tcp
    $ sudo firewall-cmd --reload

  Primary / Standby 서버:
    $ sudo firewall-cmd --permanent --add-port=5432/tcp
    $ sudo firewall-cmd --permanent --add-port=8008/tcp
    $ sudo firewall-cmd --reload


================================================================
  5. 실행 가이드 (단계별)
================================================================

  ■ STEP 1. 패키지 다운로드 (외부망 서버에서 실행)
  ─────────────────────────────────────────────────

  1) 스크립트에 실행 권한 부여
     $ chmod +x postgresql_download_0.6.sh

  2) 스크립트 실행
     $ ./postgresql_download_0.6.sh

  3) 입력 항목
     ┌─────────────────────────────────────────────────────────┐
     │ 항목                        │ 설명              │ 기본값│
     ├─────────────────────────────┼───────────────────┼───────┤
     │ 의존 패키지 다운로드 여부   │ rpm 패키지 수집   │ Y     │
     │ PostgreSQL 버전             │ 설치할 PG 버전    │ 17.9  │
     │ HA 패키지 다운로드 여부     │ etcd + Patroni    │ N     │
     │ etcd 버전 (HA 선택 시)      │ etcd 버전         │ 3.5.17│
     └─────────────────────────────┴───────────────────┴───────┘

  4) 결과물 확인
     $ ls -lh postgresql/
     $ ls -lh postgresql/installer/

  5) 폐쇄망 서버로 전송
     $ scp -r postgresql/ postgres@폐쇄망서버:~/


  ■ STEP 2. PostgreSQL 설치 (폐쇄망 서버에서 실행)
  ─────────────────────────────────────────────────

  [single 모드]
  설치 대상 서버에서 postgres 유저로 실행:

    $ cd ~/postgresql
    $ chmod +x postgresql_install.sh
    $ ./postgresql_install.sh

  [HA 모드]
  etcd 서버에서 postgres 유저로 실행:

    $ cd ~/postgresql
    $ chmod +x postgresql_install.sh
    $ ./postgresql_install.sh

  입력 항목 (HA 모드 기준):
     ┌─────────────────────────────────────────────────────────┐
     │ 항목                   │ 설명                           │
     ├────────────────────────┼────────────────────────────────┤
     │ 설치 모드              │ 1=single / 2=ha                │
     │ 클러스터 이름          │ Patroni 클러스터 식별자        │
     │ etcd 서버 IP/호스트    │ 현재(etcd) 서버 주소           │
     │ Primary DB IP/호스트   │ Primary 서버 주소              │
     │ Standby DB IP/호스트   │ Standby 서버 주소              │
     │ SSH 포트               │ 기본 22                        │
     │ PostgreSQL 포트        │ 기본 5432                      │
     │ 복제 유저명            │ 기본 replicator                │
     │ 복제 유저 패스워드     │ 직접 입력                      │
     │ Primary CPU / Memory   │ Primary 서버 리소스            │
     │ Standby CPU / Memory   │ Standby 서버 리소스 (별도 입력)│
     │ 엔진 설치 경로         │ 기본 /postgres                 │
     │ Data 경로              │ 기본 /pgdata                   │
     │ Archive 사용 여부      │ Y/n                            │
     │ Backup 사용 여부       │ Y/n                            │
     └────────────────────────┴────────────────────────────────┘


================================================================
  6. 설치 동작 순서
================================================================

  ■ single 모드 설치 순서
  ─────────────────────────────────────────
  1. installer/ 디렉토리 및 패키지 확인
  2. 입력값 수집 (CPU, Memory, Port, 경로 등)
  3. 의존 패키지(rpm) 로컬 설치
  4. 디렉토리 생성 (엔진, 데이터, 로그, 아카이브, 백업)
  5. PostgreSQL 소스 빌드 (configure → make → make install)
  6. .postgresrc 환경변수 파일 생성 및 .bashrc 등록
  7. postgresql.conf 생성 (서버 리소스 기반 자동 계산)
  8. initdb 실행 (DB 초기화)
  9. 백업 스크립트 생성 및 cron 등록 (Backup 선택 시)
  10. PostgreSQL 기동
  11. 복제 유저 생성 및 pg_hba.conf 업데이트 (Backup 선택 시)


  ■ HA 모드 설치 순서
  ─────────────────────────────────────────

  [PHASE 1] etcd 설치 (etcd 서버 로컬)
  ────────────────────────────────────
  1. etcd tar.gz 압축 해제 및 바이너리 설치 (/usr/local/bin)
  2. etcd 설정 파일 생성 (/etc/etcd/etcd.conf)
  3. systemd 서비스 등록 및 etcd 기동
  4. etcd 헬스체크 확인

  [PHASE 2] PostgreSQL 빌드 (etcd 서버 로컬)
  ────────────────────────────────────────────
  5. 의존 패키지(rpm) 설치
  6. PostgreSQL 소스 빌드 (configure → make → make install)
     → 빌드 결과물을 Primary/Standby 로 scp 복사하기 위한 준비

  [PHASE 3] Primary DB 서버 구성 (원격 SSH)
  ────────────────────────────────────────────
  7.  Primary 서버 디렉토리 생성 (SSH)
  8.  엔진 영역 scp 복사: etcd 서버 → Primary
  9.  의존 패키지(rpm) 전송 및 설치 (런타임 라이브러리)
  10. Patroni pip wheel 전송 및 설치
  11. .postgresrc 환경변수 설정
  12. postgresql.conf 생성 (Primary 리소스 기준) 및 전송
  13. initdb 실행
  14. patroni.yml 생성 (etcd 연동, 복제 유저, pg_hba 설정 포함)
  15. systemd Patroni 서비스 등록

  [PHASE 4] Standby DB 서버 구성 (원격 SSH)
  ────────────────────────────────────────────
  16. Standby 서버 디렉토리 생성 (SSH)
  17. 엔진 영역 scp 복사: Primary → Standby
      (etcd 서버 거치지 않고 직접 복사)
  18. 의존 패키지(rpm) 전송 및 설치
  19. Patroni pip wheel 전송 및 설치
  20. .postgresrc 환경변수 설정
  21. postgresql.conf 생성 (Standby 리소스 기준) 및 전송
  22. patroni.yml 생성 (Standby 전용 설정)
  23. systemd Patroni 서비스 등록

  [PHASE 5] Patroni 기동 및 클러스터 확인
  ────────────────────────────────────────────
  24. Primary Patroni 기동 (25초 대기: initdb + 부트스트랩)
  25. Standby Patroni 기동 (40초 대기: pg_basebackup 자동 클론)
  26. patronictl list 로 클러스터 상태 확인

  [PHASE 6] etcd 서버 정리
  ────────────────────────────────────────────
  27. etcd 서버의 엔진 영역 삭제 (빌드 결과물 제거)


================================================================
  7. 디렉토리 구조
================================================================

  다운로드 결과물 (postgresql_download_0.6.sh 실행 후):

    postgresql/
    ├── PKG.tar.gz                        ← dnf 의존 패키지 (rpm)
    ├── PKG_download.log                  ← 다운로드 로그
    ├── postgresql_install.sh             ← 설치 스크립트 (자동 생성)
    └── installer/
        ├── postgresql-17.9.tar.gz        ← PostgreSQL 소스
        ├── etcd-v3.5.17-linux-amd64.tar.gz  ← etcd 바이너리 (HA 시)
        └── patroni_pkgs.tar.gz           ← Patroni pip wheel (HA 시)


  설치 후 서버 구조 (기본 경로 기준):

    /postgres/
    └── app/                              ← PostgreSQL 엔진
        ├── bin/                          ← 실행 파일 (psql, pg_ctl 등)
        ├── lib/                          ← 라이브러리
        └── etc/
            ├── pg_basebackup.sh          ← 백업 스크립트 (Backup 선택 시)

    /pgdata/
    ├── data/                             ← PostgreSQL 데이터 영역
    │   ├── postgresql.conf
    │   ├── pg_hba.conf
    │   └── ...
    └── log/                              ← 로그 파일
        ├── postgresql-YYYY-MM-DD.log
        ├── pg_install.log
        └── ha_setup.log                  ← HA 구성 로그 (HA 시)

    /pgbackup/
    ├── arc/                              ← WAL 아카이브 (Archive 선택 시)
    └── back/                             ← 백업 데이터 (Backup 선택 시)


================================================================
  8. 주요 파일 설명
================================================================

  /etc/patroni/patroni.yml
    Patroni 설정 파일. 클러스터명, etcd 연결 정보,
    PostgreSQL 경로, 복제 유저 인증 정보 등을 포함.

  /etc/systemd/system/patroni.service
    Patroni systemd 서비스 파일.
    서버 재기동 시 자동 기동 (enable 상태).

  /etc/systemd/system/etcd.service
    etcd systemd 서비스 파일 (etcd 서버).

  ~/.postgresrc
    PostgreSQL 환경변수 파일 (PGHOME, PGDATA, PGPORT 등).
    ~/.bashrc 에서 자동 로드됨.


================================================================
  ■ 주요 운영 명령어 (HA 모드)
================================================================

  클러스터 상태 확인:
    patronictl -c /etc/patroni/patroni.yml list

  계획된 역할 전환 (Switchover):
    patronictl -c /etc/patroni/patroni.yml switchover pg-cluster

  강제 Failover 테스트:
    patronictl -c /etc/patroni/patroni.yml failover pg-cluster

  etcd 상태 확인:
    etcdctl --endpoints="http://etcd서버IP:2379" endpoint health

  Patroni 서비스 상태:
    sudo systemctl status patroni
